# ClinData Labs Consulting LLC website

A responsive, static corporate website built with HTML, CSS, and JavaScript.

## Files
- `index.html` — all page content
- `styles.css` — styling and responsive layout
- `script.js` — mobile navigation and copyright year

## Publish
Upload the three website files to the **root** of your GitHub repository. Connect that repository to Cloudflare Pages with **Framework preset: None**, **Build command: (blank)**, **Build output directory: /**. Alternatively, use GitHub Pages from the main branch and root directory.

## Before sharing publicly
- The logo is a new, simple placeholder symbol, not an established registered brand mark.
- Verify leadership name, credentials, and service descriptions.
- The contact link uses `info@clindatalabs.com` and **will not receive messages until you set up that mailbox**. Replace it with a verified working email before launch.
- Do not publish patient information, passwords, or private client data.
